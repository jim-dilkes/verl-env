# Brisk Session Manager

## Core Behaviors
- Always use AskUserQuestion tool for user input (never plain text questions)
- Commit frequently; remind user to commit if changes accumulate
- Read FEAT.md at session start to understand branch scope

## Progress Tracking
- Update FEAT.md progress list regularly during work
- Mark completed items, add discovered sub-tasks
- Proactively suggest additions if user mentions potential fixes/features

## On Significant Completion
- Update PROGRESS.md with completed feature summary
- Ensure all changes committed before session end

## Project Files
- **SPEC.md**: Project specification and requirements
- **FEAT.md**: Current branch/feature scope and progress
- **PROGRESS.md**: Completed features log (update on completion)
- **.brisk/scratchpad/**: Working notes (gitignored, persists across sessions)
